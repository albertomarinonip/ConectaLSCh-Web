# SeñaLink PWA
MVP web instalable para iPhone. Incluye subtítulos por reconocimiento de voz cuando el navegador lo soporta y texto a voz.

## Publicar
Sube estos archivos a un hosting HTTPS (por ejemplo GitHub Pages). Luego abre la URL en Safari y usa Compartir → Añadir a pantalla de inicio.

Nota: el reconocimiento de voz web depende del soporte del navegador/iOS y puede no estar disponible o comportarse igual en todas las versiones.
